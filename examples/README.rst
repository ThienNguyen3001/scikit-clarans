.. _examples-gallery:

Example Gallery
===============

This gallery contains runnable Python examples showcasing the features,
clustering capabilities, and scikit-learn integrations of ``scikit-clarans``.

How to run
----------

From the repository root, run any example with:

.. code-block:: bash

    python examples/cluster_geometry/plot_clusters_blobs.py

Notes
-----

Some examples produce plots using matplotlib and will open interactive windows when
run in an interactive environment. To run in headless environments (CI, servers),
set the backend:

.. code-block:: python

    import matplotlib
    matplotlib.use("Agg")

You can also experiment interactively with ``scikit-clarans`` in your browser via the
`Google Colab Notebook <https://colab.research.google.com/drive/1JdgVaZcbS1uwY7kPQZM8DtX97R9ga31d?usp=sharing>`_.
